## How to review

1. **Watch the video (main deliverable).**
   [`Take-home task_ Building Trust in DriftMail.mp4`](./Take-home%20task_%20Building%20Trust%20in%20DriftMail.mp4) runs about 11 minutes and covers the whole task. GitHub can't preview a file this large, so open the link and click **Download** (or "View raw"), then play it locally.

2. **Use the deck alongside the video (optional).**
   [`Drift-mail-walkthrough-deck.pdf`](./Drift-mail-walkthrough-deck.pdf) holds the slides shown in the video. Open it in GitHub's PDF viewer or download it.

3. **Try the prototype for a closer look at the interactions and UX (optional).**
   GitHub shows [`Driftmail Inbox Prototype.html`](./Driftmail%20Inbox%20Prototype.html) as source code. Download it and open it in Chrome, Safari or Firefox. It needs no setup.
   - The dark bar at the top jumps straight to either user story.
   - **Reset** brings the prototype back to its starting state.
